Interactive Cam Explorer

Drag points on the displacement diagram to reshape the cam. Drag matching points on the cam profile to update the displacement diagram. This model uses a radial plate cam with an in-line translating follower.

1. Displacement diagram

Horizontal axis: cam rotation angle θ. Vertical axis: follower lift.

2. Cam profile

Radius = base circle radius + follower displacement. The displayed profile changes with follower type.

Controls

Teaching notes

For a radial cam with an in-line translating follower, each angle on the displacement diagram maps to a pitch curve radius.
